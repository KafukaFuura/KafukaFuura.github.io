# 高等数学 · 每日一题

学生入口：<https://kafukafuura.github.io/daily/>

备题工具：<https://kafukafuura.github.io/daily/editor.html>

此栏目与已有的 `calculus-tree/` 知识树同属一个 GitHub Pages 网站。学生每天看到当日题目，自行展开提示或完整解答，往期题目可以补做。正式题库尚未填入时，页面提供明确标注的示例题，供试用页面功能。

## 准备和发布题目

1. 打开备题工具。页面会先读取线上 `questions.json`；发现本机草稿时，会显示“恢复本机草稿”按钮，由你决定是否恢复。
2. 点击“新建题目”，填写发布日期、标题、知识点、难度、用时、题干和完整解答。提示可以留空。
3. 点击“预览排版”检查文字与公式，再点击“保存到本机题库”。同一天最多安排一道题，每道题的标识必须唯一。
4. 准备好一批题后，点击“下载题库”，得到 `questions.json`。如浏览器自动给文件名添加了数字后缀，请恢复为准确的 `questions.json`。
5. 点击“前往 GitHub 上传”，登录有仓库写权限的账号，将该文件上传到 `KafukaFuura/KafukaFuura.github.io` 仓库的 `daily/` 目录，替换同名文件并提交。等待 GitHub Pages 完成部署，再刷新学生页面核对。

备题工具只编辑本浏览器中的草稿，不能直接改动线上内容。没有账号或仓库写权限的访问者也能使用本地备题功能，但无法替换网站题库。备题工具加载线上失败时会明确提示，切勿将空题库误当成线上最新内容覆盖上传。

导入文件会先验证结构，通过后才询问是否替换当前本机题库。恢复旧草稿后，请核对其是否包含最近已发布的题目。导出题库包含完整题目列表，应保留历史题目，方便学生补做。

## 日期、解答和完成记录

所有发布日期按 `Asia/Shanghai`（北京时间）解释。页面根据访问者设备的当前时间计算北京时间，显示当天排期；日期到了才在正常界面展示对应题目。日期计算由网页完成，无需每天重新部署或运行定时任务。设备时间设置错误会影响展示日期。

题库需要提前持续补充。没有安排题目的日期不会自动生成新题，也不会把最后一道题伪装成新的每日题目。正式题目中的解答默认收起，学生可按自己的进度展开。完成标记与展开答案分别处理。

学生的完成记录保存在当前浏览器，换设备、换浏览器或清除网站数据后不会自动同步。浏览器禁止本地存储时，页面仍可阅读题目和解答，完成状态可能无法保存。

这是公开静态练习网站。题目、未到日期的排期和解答都可能通过公开仓库或下载的数据文件查看；折叠答案用于学生自主练习，不提供考试保密。请只上传教学内容，不要在题库中放入学生个人信息、账号凭据或其他私密材料。

## 文字与数学公式

题干、提示和解答使用普通文字，换行会保留。正文不接受 HTML。

行内公式写作 `\(x^2\)`；独立成行的公式写作 `\[f'(x)=2x\]`。在备题工具中直接输入这些内容即可，它会在导出 JSON 时处理反斜杠转义。

直接编辑 JSON 文件时，反斜杠需要转义，例如正文字符串为 `"求 \\(f(x)=x^2\\) 的导数。"`。每道题发布后尽量保留原来的 `id`，以维持学生完成记录与题目的对应关系。

## 题库结构

顶层字段为 `version`、`timeZone`、`title` 和 `questions`。当前格式版本为 `1`，课程时区为 `Asia/Shanghai`。每题包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一且稳定的题目标识 |
| `releaseDate` | 发布日期，格式 `YYYY-MM-DD` |
| `title` | 题目标题 |
| `topic` | 知识点 |
| `difficulty` | 难度文字 |
| `minutes` | 建议用时，1 至 180 的整数 |
| `statement` | 题干，必填 |
| `hint` | 提示，可为空字符串 |
| `solution` | 完整解答，必填 |

部署目录保持 `daily/`，其中 `questions.json` 是正式题库。示例题与正式题库分开，示例不会自动加入正式排期。
